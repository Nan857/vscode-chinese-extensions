# Even Better TOML（社区简体中文版）

基于 tamasfe.even-better-toml 0.21.2 官方通用 VSIX 制作；独立身份为 local-chinese.even-better-toml-zh，不是上游官方发行。

VS Code 简体中文（zh-cn）界面下显示中文设置说明、命令标题和扩展自身提示；其他语言使用英文回退。保留原命令、配置键、默认值、枚举、语法文件、请求协议、服务器/WASM 字节及原始许可证。诊断正文、schema 名称/说明、异常正文与用户数据保留原文。

与 tamasfe.even-better-toml 原版互斥，现有 evenBetterToml 设置继续适用。需要 VS Code 1.90.0 及更新版本。

本次验证包含固定字节、两次确定性构建、JSON/NLS、JavaScript 语法及隔离命令回调；尚未执行原生扩展宿主、实际格式化/语言服务器/WASM、可见编辑器、Windows 或其他系统运行验证。universal 表示包的平台声明，不是跨系统运行证明。
